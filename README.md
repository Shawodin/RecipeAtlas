# 🧭 Рецептный компас (RecipeAtlas)

**Аддон для World of Warcraft 3.3.5a (WotLK, в том числе Sirus): показывает, какие рецепты твоих профессий ещё не изучены, где их взять, и ставит метки на карту.**

## Возможности

- 📜 **Список неизученных рецептов** по всем 11 профессиям: алхимия, кузнечное дело, кулинария, наложение чар, инженерное дело, горное дело, первая помощь, начертание, ювелирное дело, кожевничество, портняжное дело. В базе 3500 рецептов.
- 🔎 **Где взять:** наставники, торговцы (с ценой и пометкой об ограниченном запасе), добыча с NPC (с шансом), мировая добыча, задания, сундуки, предметы-контейнеры, рыбалка, открытия. Для каждого источника есть зона и координаты.
- 🗺️ **Метки на карте мира и миникарте.** Круглые значки: цвет обводки — тип источника, внутри — иконка профессии, в углу — число рецептов. Внизу карты есть легенда. Близкие метки объединяются в группы.
- 🎯 **«На карте»:** на карте остаются только источники выбранного рецепта, и они пульсируют.
- ⭐ **Отслеживание рецептов.** До 8 рецептов висят на экране, как задания: ближайший источник, зона, координаты и расстояние в ярдах. Панель сама встаёт под список заданий, включая новый трекер Sirus. Изученные рецепты убираются сами.
- 💬 **Подсказки:**
  - у предмета-рецепта (в сумках, на аукционе, в ссылках): «уже изучен», «не изучен — можно учить!» или «нужен навык N»;
  - над NPC: сколько твоих неизученных рецептов он учит, продаёт или с него падает.
- 🟢 **Подсветка у торговца:** неизученные рецепты — зелёным, рецепты, для которых не хватает навыка, — оранжевым.
- 🎃 **Праздничные рецепты подписаны**, например «(Зимний Покров)». Можно скрыть праздники, которые сейчас не идут (по игровому календарю).
- ⚔️ **Фильтры:** по навыку, своей фракции, своему классу (например, классовые инженерные очки), типам источников. Есть поиск по названию рецепта, NPC и заданию.
- 🔄 **Изученные рецепты определяются автоматически**, когда открываешь окно профессии. Во время крафта аддон не тормозит.
- 📍 **Поддержка TomTom**, если он установлен: точки маршрута по ПКМ на метке и из панели отслеживания.
- 🧩 **Без зависимостей:** нужные библиотеки уже внутри.
## Установка

1. Скачай архив из раздела **[Releases](../../releases)** (файл `RecipeAtlas-x.y.z.zip`).
2. Распакуй его в `World of Warcraft/Interface/AddOns/`. Должно получиться `Interface/AddOns/RecipeAtlas/RecipeAtlas.toc`.
3. **Полностью запусти игру.** Если игра была открыта, выйди из неё и зайди снова: `/reload` не подхватывает новые файлы аддона.
4. Открой окно каждой своей профессии один раз, чтобы аддон запомнил, что ты уже изучил.

> ⚠️ Если качаешь через **Code → Download ZIP**, папка будет называться `RecipeAtlas-main`. Переименуй её в `RecipeAtlas`, иначе игра не увидит аддон.

**Обновление:** удали старую папку `RecipeAtlas`, положи новую и полностью перезапусти игру. Настройки и изученные рецепты сохранятся.

## Как пользоваться

| Действие | Что делает |
|---|---|
| `/recipes` или кнопка у миникарты | открыть или закрыть окно |
| ПКМ по кнопке у миникарты | включить или выключить метки на карте |
| ЛКМ / ПКМ по профессии | показать или скрыть профессию / оставить только её |
| Клик по рецепту | карточка: источники, координаты, шансы, цена, репутация |
| Shift+клик по рецепту | ссылка в чат |
| Alt+клик по рецепту или кнопка «Отслеживать» | отслеживать рецепт |
| «На карте» | показать на карте только источники этого рецепта |
| ЛКМ по метке на карте | список рецептов этой точки |
| ПКМ по метке на карте | точка TomTom |
| Shift при наведении на метку поверх значка задания | выбрать метку, а не задание |

**Панель отслеживания:**
- ЛКМ — открыть рецепт в окне компаса;
- Ctrl+ЛКМ — показать на карте;
- Shift+ЛКМ — точка TomTom к ближайшему источнику;
- ПКМ — убрать из отслеживания;
- заголовок можно перетаскивать, ЛКМ по нему сворачивает панель.

### Команды

| Команда | Описание |
|---|---|
| `/recipes` | окно аддона |
| `/recipes scan` | пересканировать открытую профессию |
| `/recipes map` | включить или выключить метки на карте |
| `/recipes minimap` | показать или скрыть кнопку у миникарты |
| `/recipes faction` | скрывать или показывать источники другой фракции |
| `/recipes class` | скрывать или показывать рецепты других классов |
| `/recipes holiday` | скрывать или показывать праздники, которые сейчас не идут |
| `/recipes track` | показать или скрыть панель отслеживания |
| `/recipes track reset` | вернуть панель отслеживания под список заданий |
| `/recipes npc` | включить или выключить подсказку над NPC |
| `/recipes merchant` | включить или выключить подсветку у торговца |
| `/recipes reset` | забыть изученные рецепты этого персонажа |
| `/recipes debugmap` | диагностика меток на карте |
| `/recipes help` | список команд |

## Как это работает

- **База рецептов** (`RecipeAtlasData.lua`) собрана заранее из открытой базы эмулятора [CMaNGOS WotLK](https://github.com/cmangos/wotlk-db) и файлов клиента 3.3.5a. В неё входят наставники, торговцы, добыча с учётом вложенных таблиц и героических версий, задания, открытия, требования к навыку, репутации, классу и фракции, праздничные NPC, координаты (включая оба уровня Даларана) и иконки создаваемых предметов.
- **Зона точки** определяется по открываемым при исследовании участкам карты (`WorldMapOverlay.dbc`). Поэтому NPC на границе зон, например Тёмные берега и Оскверненный лес, попадают в правильную локацию.
- **Изученные рецепты:** когда открываешь окно профессии, аддон на мгновение сбрасывает её фильтры, читает ссылки на рецепты и возвращает всё как было. Повторно он сканирует только после изучения нового рецепта.

## Ограничения

- База описывает **стандартный WotLK 3.3.5a**. На Sirus часть рецептов, торговцев и точек появления может отличаться: клиентский аддон не видит базу сервера.
- Имена NPC, заданий и подземелий в базе **английские**. Названия рецептов и зон показываются на языке клиента.
- Источники в подземельях показываются в карточке, но без метки на карте.
- Мировая добыча (больше 25 видов мобов) показывается сводкой, без меток.

## Частые вопросы

**Новая функция не работает после обновления.** Полностью перезапусти игру, `/reload` не поможет. Если файл аддона не загрузился, аддон сам напишет об этом в чат.

**Профессия показывает серое число.** Она ещё не просканирована: открой её окно. Серое число — это сколько всего рецептов этой профессии в базе.

**Метка стоит не там или пропала в какой-то зоне.** Открой эту зону на карте, введи `/recipes debugmap` и приложи вывод к [issue](../../issues).

**Рецепт есть на сервере, но не в аддоне (или наоборот).** Это отличие Sirus от стандартной 3.3.5a. Создай issue с названием рецепта и тем, где его берут на сервере.

## Пересборка базы (для разработчиков)

Аддону это не нужно, он работает на готовом `RecipeAtlasData.lua`.

1. Скачай `wotlk-sqlite-db.zip` со страницы [релизов cmangos/wotlk-db](https://github.com/cmangos/wotlk-db/releases) и распакуй `wotlkmangos.sqlite`.
2. Возьми DBC-файлы клиента 3.3.5a (build 12340): `WorldMapArea`, `WorldMapOverlay`, `DungeonMap`, `Map`, `AreaTable`, `Faction`, `FactionTemplate`, `SkillLine`, `SkillLineAbility`, `Spell`. Например, из [Elwynsiaa/data](https://github.com/Elwynsiaa/data).
3. Положи всё в одну папку и запусти:

```bash
RECIPEATLAS_WORK=/путь/к/папке python3 tools/build_catalog.py
```

Нужен Python 3.8+, сторонние пакеты не требуются. Сборка занимает несколько секунд.

## Структура

```
RecipeAtlas/
├── RecipeAtlas.toc        # описание аддона для игры
├── RecipeAtlasData.lua    # готовая база рецептов (генерируется)
├── Core.lua               # данные, фильтры, сканирование профессий, команды
├── UI.lua                 # главное окно
├── Map.lua                # метки на карте мира и миникарте

├── Tracker.lua            # панель отслеживания рецептов
├── Libs/                  # LibStub, Astrolabe 0.4
├── tools/build_catalog.py # сборщик базы
├── SOURCES.md             # источники данных и лицензии
└── CHANGELOG.md
```

**RecipeAtlas** is a standalone addon for World of Warcraft 3.3.5a (WotLK, including the Sirus server). For all 11 professions it shows which recipes you haven't learned yet and where to get each one: trainers, vendors, mob drops with chances, quests, chests, containers, fishing and discoveries. Every source comes with its zone and coordinates.

Features: round world map and minimap pins with a colour legend, a recipe tracker that sits under the quest tracker and shows the distance to the nearest source, item and NPC tooltip info, merchant highlighting, holiday tags, and class, faction and skill filters. TomTom is optional. The UI is in Russian.

Install: extract into `Interface/AddOns/RecipeAtlas` and fully restart the game. Data comes from CMaNGOS WotLK DB and 3.3.5a client DBC files. Licensed under GPL-3.0.
